# LAC Session Document Pack — TLE

Full paper trail for one Learning Action Cell (LAC) session, built per
[DepEd Order No. 35, s. 2016](https://www.deped.gov.ph/2016/06/07/do-35-s-2016-the-learning-action-cell-as-a-k-to-12-basic-education-program-school-based-continuing-professional-development-strategy-for-the-improvement-of-teaching-and-learning/)
and standard PMES MOV format (indicator 7.4.2 evidence). All names
below are **sample placeholders** — swap before printing/signing.

## Before you print/submit

1. **Logo** — every file has a `[SCHOOL LOGO HERE]` line at the top.
   Generate your logo from DepEd's logo generator, paste/insert the
   image there (Word/Google Docs: replace the placeholder text with
   the image; keep centered above the school name).
2. **Find-and-replace these placeholders** in every file:
   - `[SCHOOL NAME]`, `[DIVISION]`, `[DISTRICT]`
   - `[DATE]`, `[VENUE]`, `[TIME START]`, `[TIME END]`
3. **Names** — `Dr. Ma. Teresa D. Villanueva` (School Head),
   `Mr. Ramon C. Santos` (LAC Leader), and the 8 teacher names in each
   file are samples. Replace with your actual signatories, or keep
   them if this is a dry run.
4. Convert to `.docx`/PDF for actual signing if needed — these are
   plain markdown, not final print layout.

## Regenerating for a future session

Don't hand-edit all 9 files again next time. Use the
`lac-session-docs` skill (`.claude/Skills/lac-session-docs/SKILL.md`)
— give it the new topic/date/venue/participants and it regenerates
the full set with consistent names across every file.
