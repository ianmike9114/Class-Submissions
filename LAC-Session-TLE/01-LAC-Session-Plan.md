## Session Title

Leveraging the DepEd Student LMS for TLE Instruction — Digital
Submission, Grading, and Class Record Management

## Rationale

TLE teachers currently manage student output links, scoring, and class
records manually across chat groups and spreadsheets. This session
introduces a purpose-built, zero-cost web app (Firebase Auth +
Firestore, Google Sign-In only — no paid tier) that lets students
submit assignment links and lets teachers grade, publish scores, and
track submissions from one dashboard, so the 8 TLE teachers present can
adopt it across their own subjects/sections.

## Objectives

By the end of the session, participants will be able to:

1. Create their own teacher account/subject/section/assignment in the
   LMS and generate a section join-code or QR code for students.
2. Review a sample student submission, encode a score, and publish it
   so the student sees the result.
3. Identify at least one of their own TLE classes where they will pilot
   the LMS within two weeks.

## Materials/Resources

- Laptop/desktop with browser, stable internet connection per teacher
- LMS URL (GitHub Pages link) and each teacher's Gmail account
- Projector/screen for live walkthrough
- Sample assignment + sample student submission link for demo
- Attendance sheet, session evaluation slips
