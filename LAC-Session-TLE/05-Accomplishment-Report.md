# LEARNING ACTION CELL (LAC) SESSION — ACCOMPLISHMENT REPORT

**School:** [SCHOOL NAME] | **Division:** [DIVISION] | **Region:** [REGION]
**Topic:** Leveraging the DepEd Student LMS for TLE Instruction —
Digital Submission, Grading, and Class Record Management
**Date:** [DATE] | **Time:** [TIME START]–[TIME END] | **Venue:** [VENUE]
**LAC Leader:** Mr. Ramon C. Santos | **Facilitator:** Ms. Angelica P. Reyes
**Number of Participants:** 8 TLE teachers

## I. Objectives

1. Orient TLE teachers on setting up and using the DepEd Student LMS
   for their own subjects/sections.
2. Demonstrate the grading and score-publishing workflow.
3. Secure a pilot commitment from each teacher.

## II. Summary of Proceedings

The session opened with a review of the previous LAC session's
agreements, followed by an orientation on the LMS — a zero-cost,
Firebase-based tool (Google Sign-In, Firestore only, link-based
submissions, no file uploads) built specifically to fit DepEd's
no-budget constraint. The Facilitator conducted a live demo covering
account setup, section join-codes/QR, assignment creation, submission
review, single-score grading, and publishing. Participants then
completed a hands-on workshop, each setting up a test subject/section
on their own account, followed by open sharing and Q&A.

## III. Teachers' Contributions

Participants raised practical concerns grounded in their own classes —
non-Gmail students, per-teacher data isolation, and how link-only
submissions work for practical/output-based TLE tasks (e.g. photo
documentation of a cooking or livelihood output, sharable Drive links).
These questions shaped the Q&A and were resolved during the session.

## IV. Output/Result

- 8/8 teachers successfully created a test subject/section/assignment.
- Each teacher committed to a specific pilot class and target date
  (see Action Plan).

## V. Agreements/Action Points

See [06-Action-Plan-and-Agreements.md](06-Action-Plan-and-Agreements.md).

## VI. Facilitator's Reflection

Teachers engaged actively once they saw the tool solved a concrete
pain point — tracking scattered submission links across chat
threads/spreadsheets. Next session should review pilot results and
gather concrete feedback on the link-only submission constraint for
practical-output TLE tasks.
